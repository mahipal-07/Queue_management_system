# Smart Queue Management System 

A simple Java-based Smart Queue Management System for small clinics or cafes.  
This project simulates queue operations like adding customers, serving them, and tracking queue position.

Features :- 

Add new customer to the queue
View queue status
Serve customers in FIFO order
Track a customer's position in queue
Built with core Java (no frameworks)

## Technologies Used

- Java
- Java Collections (Queue)
- Command Line Interface (CLI)
